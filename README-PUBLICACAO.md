# CyberLeigos — publicação no GitHub Pages

1. Extraia o ZIP.
2. Envie **todo o conteúdo** para a raiz do repositório GitHub.
3. No repositório, abra **Settings → Pages**.
4. Em Build and deployment, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação. O ponto de entrada é `index.html`.

## O que vem no pacote
- Páginas separadas para os assuntos do HTML original.
- Quizzes originais preservados e perguntas extras.
- Três tarefas diárias com 10 XP por acerto.
- Minigames educativos com cenários fictícios e explicações.
- XP, sequência diária e atividades concluídas salvos localmente.
- Página de conta opcional preparada para Supabase.
- Animações discretas que respeitam a preferência por movimento reduzido.

## Contas
Sem conta, o progresso fica no navegador atual. Para sincronizar entre dispositivos, configure o Supabase seguindo `CONFIGURACAO-SUPABASE.md`.
GitHub Pages é hospedagem estática, então o serviço de autenticação precisa ser externo.
